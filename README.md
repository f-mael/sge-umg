# Sistema de Gestión Escolar (SGE)

Proyecto desarrollado para el curso de Programación II en la Universidad Mariano Gálvez de Guatemala.

## Descripción
Aplicación desarrollada en Java para la gestión y control escolar, facilitando el registro de alumnos, administración de cursos y asignación de notas.
